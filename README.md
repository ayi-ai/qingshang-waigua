# 情商外挂

消息发出去之前，先改一遍。

把一句带火气的话贴进去，选好对方是谁、想要什么语气，它先标出原话里最容易惹毛对方的几个字，再给你一条能直接发的说法。方法来自马歇尔·卢森堡《非暴力沟通》：观察、感受、需要、请求。

- 七种对象：客户、上级、同事、下属、伴侣、家人、朋友，每种有自己的说话规矩
- 三档语气：温和、坚定、直接。选坚定或直接时，立场不会被改软
- 两种用法：改自己想发的话，或者帮你回别人发来的话
- 只有两个文件，不用装任何依赖，兼容任何 OpenAI 格式的模型接口

## 快速开始

需要 Python 3。macOS 一般自带，在终端里输入 `python3 --version` 能看到版本号就行；Windows 去 python.org 下载安装，安装时勾上 Add Python to PATH。

1. 下载这个仓库：点页面上的 **Code → Download ZIP**，解压到桌面，文件夹名改成 `qingshang-waigua`。

2. 在终端里进入文件夹并启动：

   ```
   cd ~/Desktop/qingshang-waigua
   python3 app.py
   ```

   Windows 用 `python app.py`。

3. 终端会显示两行：

   ```
   情商外挂 已启动：http://127.0.0.1:8787  模型：deepseek-flash
   设置口令：xxxxxxxxxxxx（点页面右上角的设置时输入，只在这台电脑的终端里显示，别发给别人）
   ```

4. 浏览器打开 `http://127.0.0.1:8787`，点右上角的 **设置**，输入终端里的设置口令。

5. 选服务商，填 API Key，点 **从接口拉取模型列表**，勾选要用的模型，保存。

6. 回到首页，贴一句话，点 **帮我改**。快捷键是 ⌘ + Enter（Windows 是 Ctrl + Enter）。

在终端里按 Ctrl + C 就能停掉服务。

## 只想先看看界面

不接模型、不花钱：

```
MOCK=1 python3 app.py
```

示例模式下页面顶部会有黄色提示，不管输入什么，返回的都是同一段固定示例。

## 设置面板

| 设置 | 说明 |
|---|---|
| 服务商 | 内置 OpenAI、DeepSeek、阿里云百炼、Kimi、智谱、硅基流动、OpenRouter、AIsa，选了会自动填地址；也可以选“自定义”填任意 OpenAI 兼容地址。地址以各平台文档为准 |
| API Key | 只保存在本机的 `config.json`，文件权限只有你自己能读；页面上只显示打码后的样子 |
| 允许使用的模型 | 首页下拉框只显示你勾选的模型；保存时会去这家平台的模型列表里核对，名字不对会被拦下 |
| 次数上限 | 所有使用者加起来每分钟、每天最多用几次，默认 10 次和 200 次，填 0 表示不限 |

不想用设置面板，也可以用环境变量：

```
LLM_BASE_URL="接口地址" LLM_API_KEY="你的密钥" LLM_MODEL="模型名" python3 app.py
```

设置面板里保存过的配置优先。

## 分享给别人用

`127.0.0.1` 只有这台电脑自己能打开。想让同事、朋友用，可以用 [UUMit](https://uumit.com) 的电脑客户端给它一个链接：客户端会认出正在运行的工具，点一下拿到网址，再选“只有我”“我和我邀请的人”或“所有人”。

分享出去之后要注意：

- 你的电脑和工具都得开着、联网，别人才能用
- 每个人每用一次，花的都是你的模型费用，记得在设置里设好次数上限
- 设置口令只在你的终端里显示，别人通过链接打开也改不了你的配置

## 隐私

工具本身不保存任何聊天记录。你贴进去的原话会发给你配置的模型接口处理，敏感的名字、金额可以先换成【】，改完再填回去。

## 跑不起来时

| 你看到的 | 原因 | 怎么办 |
|---|---|---|
| 右上角显示“未配置模型接口” | 还没填 API Key | 打开设置填上 |
| 模型接口返回 400 | 多半是模型名在这家平台上不存在 | 设置里重新拉取模型列表并勾选 |
| 模型接口返回 401 | 密钥不对或过期 | 去平台控制台重新生成 |
| 模型接口返回 429 | 调用太频繁或余额不足 | 稍等再试，或去平台充值 |
| 终端报 `Address already in use` | 8787 端口被占用 | 用 `PORT=8788 python3 app.py` 换个端口 |
| 改了代码或设置不生效 | 服务还是旧的 | Ctrl + C 停掉，再 `python3 app.py` |

## 文件

```
app.py       服务端：提示词、七种对象的说话规矩、模型调用、设置和次数上限

```

想改说话规矩，直接改 `app.py` 里的 `WHO`、`TONE` 和 `SYSTEM_PROMPT`。
